# Workflow: Initialize Frontend Web Application

## Overview

This workflow initializes a Vue.js frontend application with TypeScript, following the established memory-bank standards and integrating with backend APIs.

## Prerequisites

- Memory bank is initialized and populated
- Node.js and npm installed
- Backend API available (preferably with OpenAPI documentation)

## Step 1: Project Setup

1. Check **memory-bank** for `techContext` files to identify the defined frontend tech stack.
2. Confirm with user that the frontend tech stack is correct.
3. Ask **where to create the frontend project** (path/folder, relative to backend or separate).
4. Scaffold the frontend project structure (Vue.js with TypeScript).

## Step 2: Development Environment

1. Set up development server with Vite.
2. Configure build system and development tooling.
3. Set up linting, formatting, and code quality tools.
4. Configure environment variables for different stages (dev, staging, prod).

## Step 3: API Integration

1. Check if backend has OpenAPI/Swagger documentation enabled.
2. Generate TypeScript API client using swagger-typescript-api:
   ```
   npx swagger-typescript-api generate --unwrap-response-data --add-readonly -p {swagger-url} -o ./src/api -n api-generated.ts
   ```
3. Create manual API client structure (if OpenAPI not available).
4. Configure API base URLs and environment-specific endpoints.
5. Set up request/response interceptors for authentication and error handling.

## Step 4: Core Application Structure

1. Set up Vue Router for client-side navigation.
2. Configure Pinia for state management.
3. Create basic application layout and navigation components.
4. Implement authentication state management and route guards.

## Step 5: UI Component Foundation

1. Set up PrimeVue component library with Tailwind CSS.
2. Create base UI components (buttons, forms, layouts).
3. Implement responsive design patterns.
4. Set up theming and design system.

## Step 6: Authentication & Security

1. Implement login/logout functionality.
2. Set up JWT token management and refresh logic.
3. Create protected route components.
4. Implement authentication state persistence.

## Step 7: Core Pages & Features

1. Create main application dashboard.
2. Implement user profile and settings pages.
3. Set up error handling pages (404, 500, unauthorized).
4. Create loading states and feedback components.

## Step 8: Optional Features

- **State Persistence**: Local storage for application state
- **PWA Support**: Service workers and offline capabilities
- **Internationalization**: Multi-language support
- **Testing Setup**: Vitest and component testing
- **Build Optimization**: Code splitting and lazy loading

## Step 9: Integration & Deployment

1. Configure production build settings.
2. Set up API proxy for development.
3. Create deployment configuration (nginx, docker).
4. Implement environment-specific configurations.

## Step 10: Finalize Frontend Setup

1. Generate comprehensive README with setup instructions.
2. Configure development scripts and tooling.
3. Verify the application builds and runs correctly.
4. Document component usage and development guidelines.
5. **Clean up redundant files** (important lesson: remove tutorial/demo code early)

## 🎯 Important Lessons Learned

### What to Include:

- **Full-Width Layout**: Remove width constraints for modern responsive design
- **PrimeVue Integration**: Use proper @primeuix/themes import and tailwindcss-primeui
- **Minimal Starting Point**: Build incrementally, add features as needed

### What to Remove Immediately:

- Vue.js demo components (HelloWorld.vue, About.vue, etc.)
- Tutorial/autogenerated content
- Empty directories that create clutter
- Demonstration code from CLI scaffolds

### State Management Strategy:

- Start with Pinia but plan for removal if going minimal
- Use reactive stores for UI state, avoid complex state for simple apps

### Authentication Implementation:

- If needed, implement JWT with interceptors
- Build login/register UI with PrimeVue form components
- Consider route guards with Vue Router

### API Integration Best Practices:

- Auto-generate client from OpenAPI when backend is ready
- Implement proper error handling with user feedback
- Use axios interceptors for auth tokens
- Handle loading states in all API calls

### Component Architecture:

- Use PrimeVue components as primary building blocks
- Create atomic design (base → feature → page components)
- Implement responsive grids and layouts
- Apply consistent design system

## Success Criteria

- Frontend application builds and runs successfully
- API integration working with proper error handling
- Authentication flow functional
- Responsive design implemented
- Component library properly configured
- Development tooling operational
